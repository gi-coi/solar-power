## Project objectives

Research the solar market in Europe (or a chosen country) and find a small story about solar adoption by public bodies. Write a short paragraph about it and build a data visualisation.

Deliverables:
- a short paragraph about a small story of solar adoption by public bodies — the story may be user-provided, and the paragraph should only be written if the user asks
- a data visualisation about that story (in `news-output/`)
- a record of the conversation with the agent (in `agent-chats/`)
- a GitHub repository containing the above (submitted as a link)

Scope: to be defined during research (record decisions + uncertainties as they arise).

Method:
- always ask for sources; document every data source as it's used — URL, publisher, access date, and what it provides (in `docs/agent-notes/sources.md`)
- fact-check data before trusting it — see the `fact-check-data` skill

## Default folder structure
```text
docs/                 = the Obsidian folder (notes, research summaries, reports)
  agent-notes/        = the agent's own notes and automated output
    sources.md        = running log of every data source (URL, publisher, access date)
    uncertainties.md  = what was uncertain/unclear during the process
agent-chats/          = (deliverable) records of the conversation with the agent
data/                 = research data — datasets and files the agent collects during research
scripts/              = code (analysis, data cleaning, packaging)
  tests/              = pytest tests
news-output/          = (deliverable) the data visualisation — a short paragraph + chart as a static web page
  data/               = packaged JSON the frontend loads (generated by scripts/)
AGENTS.md
README.md
```

## Tech guidelines
- use `uv` as the package manager
- do the heavy lifting (cleaning, aggregation, formatting) in Python under `scripts/`; keep the frontend JavaScript to simple filtering/slicing
- propose commits at meaningful checkpoints (after each working phase); commit more often when the user asks
